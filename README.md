## Overview
This project showcases an interactive Power BI dashboard developed during my internship at Sabin Vaccine Institute to support portfolio reporting and executive-level decision-making. The dashboard was built in collaboration with the Senior Finance Director to improve reporting clarity, metric standardization, and data accessibility across portfolio operations.
The dashboard includes interactive slicers, dynamic visualizations, and standardized reporting metrics designed to help stakeholders monitor portfolio performance and explore key financial and operational trends more efficiently.

## Project Highlights
- Applied DAX measures to clean, structure, and standardize reporting metrics
- Collaborated closely with finance leadership to align reporting outputs with stakeholder needs, strengthened routine reporting through iterative feedback and dashboard refinement
- Presented the dashboard to a 10-person executive team and received positive feedback for improving reporting clarity and supporting decision-making
- Conducted dashboard walkthroughs and training sessions for 40+ R&D end users to support adoption, usability, and consistent interpretation of reporting metrics
